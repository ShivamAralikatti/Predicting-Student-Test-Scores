# Predicting Student Test Scores (Kaggle: Playground Series S6E1)

This repository contains the code used to generate results for my Kaggle competition submission: **"Predicting Student Test Scores"**.
Competition link: https://www.kaggle.com/competitions/playground-series-s6e1

---

## Repository Overview

- **`main.ipynb`**  
  The primary notebook containing the full workflow and the (novel) approach used to produce the final predictions.

- **`datasets/`**  
  Contains the competition dataset files:
  - `test.csv`
  - `sample_submission.csv`

- **`submissions.csv`**  
  Generated by the code in `main.ipynb`. This is the output prediction file ready for Kaggle submission.

- **`requirements.txt`**  
  Lists the library versions used for reproducibility.

---

## Getting Started

### 1) Clone the repository
```bash
git clone https://github.com/ShivamAralikatti/Predicting-Student-Test-Scores.git
cd Predicting-Student-Test-Scores
````

### 2) Create and activate a virtual environment (recommended)

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate
```

### 3) Install dependencies

```bash
pip install -r requirements.txt
```

---

## Data Setup

1. Join the Kaggle competition and download the dataset files from the competition page.
2. Place the following files into the `datasets/` folder:

   * `train.csv`
   * `test.csv`
   * `sample_submission.csv`

> Note: The `submissions.csv` file is generated by running the notebook.

---

## Running the Project

Open and run the notebook:

```bash
jupyter notebook
```

Then run **`main.ipynb`** from top to bottom.
Once completed, it should generate:

* `submissions.csv` (predictions formatted for Kaggle submission)
